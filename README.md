# 听己 SongLib Muse

**下一首 更懂你**

听己是一款免费的私人音乐整理与推荐工具，装在你自己的 NAS、服务器或电脑上运行，你就是它的管理员。它分析你自己曲库里每首歌的声音与歌词，按你喜欢的歌单从曲库里挑出听感相近的歌。分析与推荐都在本机完成，数据不离开你的设备。

本仓库用于发布部署教程、Compose 模板、项目声明和收集反馈，不包含应用源码。

[部署教程](docs/部署教程.md) · [Compose 模板](docker-compose.yml) · [设置模板](.env.example) · [项目声明](声明.md) · [问题反馈](https://github.com/songdone/SongLibMuse-Release/issues)

## 安装

| 部署方式 | 获取 | 状态 |
|---|---|---|
| Docker / Compose | 镜像 `666uos/songlib-muse`；[Compose 模板](docker-compose.yml) + [设置模板](.env.example) | 镜像尚未发布到 Docker Hub，发布后即可使用 |
| 飞牛 fnOS | 飞牛应用中心搜索「听己 · AI音乐助理」 | 尚未上架 |

适用于飞牛、群晖、威联通、极空间、Unraid 等带 Docker 的 NAS 和 Linux 主机。需要 x86_64 设备、Docker Compose v2，建议空闲内存 4 GB 以上。完整步骤见[部署教程](docs/部署教程.md)，用法概要：

```sh
mkdir -p data models
cp .env.example .env      # 只需填写音乐文件夹 TINGJI_MUSIC_DIR
docker compose up -d
docker logs tingji        # 查看初始化口令
```

浏览器打开 `http://NAS的IP:18000`，填写口令并创建管理员。

## 功能

- 曲库分析：声音与歌词特征分析，支持闲时或定时运行、随时暂停；分析模型约 1.3 GB，安装后在网页一键下载或离线导入。
- 音乐推荐：选一个喜欢的歌单作参考，从你的曲库里挑相似的歌；可保存为歌单，导出 TXT / M3U8。
- 媒体库：接入飞牛音乐、Plex、Emby、Jellyfin、Navidrome、极音乐，自动比对文件对应关系，推荐结果可直接在这些播放器里播放，歌单可写回。
- 曲库整理：补齐歌词与封面、修正标签，写入前预览，自动备份，可撤销。
- 音源：可自行添加洛雪（LX）脚本或局域网里自建的音源服务，补全缺失的歌。听己不内置任何音源。
- 听感找歌：常见中文风格、情绪、乐器与场景描述在本机查找。
- 小己助手：接入你自己选择的大模型服务（OpenAI 兼容接口，或家里的 Ollama、LM Studio），用一句话描述想听什么。默认关闭。
- 家庭成员：管理员可为家人开账号，并逐项开放音源、下载入库、在线功能、可用的音乐文件夹与每日额度。

## 与音屿联动

[音屿 SongLib Amp](https://songlib.playsong.cn/) 是同系列的 Apple TV 与 iPhone 音乐播放器。在听己网页「客户端连接」生成配对码，在音屿里填写听己的地址和配对码即可连接：听己的推荐、歌单与曲库分析会出现在音屿里，播放走你自己的媒体服务器。只在家里用时填局域网地址即可，在外也要用时需自备域名和 HTTPS 反向代理，见[部署教程](docs/部署教程.md#四连接音屿手机电视播放器)。
